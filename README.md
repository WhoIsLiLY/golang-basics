# Go Learning Repository

This repository contains Go programming examples organized by topics.

## Modules

- **go-fundamentals**: Basic Go concepts (variables, functions, types, control flow)
- **go-stdlib**: Standard library examples (fmt, strings, time)
- **go-modules-demo**: Working with Go modules and external packages
- **go-testing**: Unit testing examples
- **go-concurrency**: Goroutines, channels, and synchronization
- **go-context-demo**: Context usage for cancellation and values
- **go-http-server**: HTTP server and client examples
- **go-json-demo**: JSON encoding and decoding
- **go-generics-demo**: Generic types and functions
- **go-embed-demo**: Embedding files into binaries

## Running Examples

Navigate to any module directory and run:

```bash
go run .
```

For tests:

```bash
go test
```

## Requirements

- Go 1.21 or later
